# Examples

Real jobs to try the builder with. Drop an `Estimation … .xlsx` onto the page to load it.

## birch-hollow

- `Estimation  Birch Hollow from 15_10_2026.xlsx`: the Logikal estimation export.
- `Estimation  Birch Hollow from 15_10_2026 (1).xlsx`: a second copy of that export,
  sent separately. It is not byte-identical to the first.
- `Birch Hollow Quotation Version 1.xlsm`: the quotation Renka made by hand, for comparison.
- `EXAMPLE - Birch Hollow Quotation.pdf` and `(landscape).pdf`: Proposal PDFs from the builder.
- `EXAMPLE - Birch Hollow quote job.json`: a saved job. Open it with **Open job**.

## allan-wilsher-highview

- `Estimation  Allan Wilsher -Highview from 15_10_2026.xlsx`: the Logikal estimation export.
- `Allan Wilsher - Highview Quotation V3.xlsm`: the quotation Renka made by hand.
